# 噛みつき専用演出

## 流れ

口攻撃の有効化イベント → 距離・前方角度・遮蔽物チェック → 掴み成立 → 操作拘束・接近 → 1回ダメージ → 後退・解放。
有効化時点で範囲外だった場合も、口HitBoxへの接触時にもう一度掴み条件を確認します。通常の腕攻撃は従来通りです。

## EnemyAttack の「噛みつき：掴み・接近」

- Enabled: オフなら従来の口接触ダメージ。
- Grab Range: 成立距離（初期1.5m）。Attack Distanceとは別。小さくすると掴みを回避しやすくなります。
- Grab Angle: ゾンビ正面からの許容角度（初期75度）。
- Contact Distance: 接近後のルート間距離（初期0.55m）。モデルに合わせて調整。
- Approach Duration: 接近時間（0.25秒）。
- Bite Delay: 掴み成立からダメージまで（0.65秒）。現在はタイマー方式。既存MouthAttackの口の動きに合わせて調整してください。
- Hold Duration: 拘束時間（1.5秒）。接近時間・ダメージ時間より短く設定しても、ダメージ後0.25秒を確保します。
- Shoulder IK Weight / Shoulder Offset: 肩へ手を寄せる強さと位置補正。Humanoidの腕・手ボーンが必要です。
- Ignore Pair Collision: 当事者2体の非Trigger Collider同士だけ衝突を無視。元から無視していたペアの設定は変更しません。
- Log Events: 掴み／噛みつきダメージのログ。

## Player / ThirdPersonCameraController の「噛みつき専用カメラ」

- Bite Camera Offset: プレイヤー基準の横・高さ・前後位置。Xを負にすれば逆側。
- Bite Look Height: 注視高さ。
- Bite Camera Roll: 画面の傾き。
- Bite Camera Blend Time: 接近画角への切り替えと復帰時間。

既存の一人称・三人称カメラの上に一時的に反映し、解放後は元の追従へ復帰します。カメラ位置は壁回避を通します。

## 安全処理・制限

掴み中は通常のゲーム入力を無効化し、PlayerのRigidbodyを固定します。ポーズは別経路です。壁や床、Triggerの被弾判定は無効化しません。
同時に拘束できるゾンビは1体。敵の被弾・死亡、攻撃終了、無効化・破棄で拘束と当事者間の衝突無視を解除します。
通常終了は最後の0.25秒で後退します。中断時は戻る経路に障害物がなければ接近開始位置へ戻して重なりを解消します。
接近経路チェックは半径0.25mの縦カプセルによる近似です。モデルの大きさや複雑な地形では調整・追加確認が必要です。
専用の被拘束クリップ／指の握り／口の肩への厳密なIKは未実装です。既存MouthAttackと腕の肩への位置補正を利用した初期版であり、実モデルの肩・口の見た目は調整が必要です。
