# 🎮 Dead Shot｜ゲーム紹介

**恐怖の中で選んだ攻略が、次に超えたいスコアになる。**

荒廃してしまった街を舞台とする、開発中の**TPS視点・エリアクリア制のサバイバルホラー型アクションゲーム**です。

敵を倒して進むか、逃げながらアイテムで切り抜けるか。自分なりの攻略で指定エリアを突破し、より高い得点を目指します。リアルな怖さが判断に重みを与え、「次はもっと上手く、高い得点でクリアしたい」という気持ちが再挑戦につながる。そんな体験を、エリア単位で手軽に繰り返せる作品を目指しています。

**「なぜ、この街は荒廃してしまったのか」**を、エリア攻略とともに知っていくシナリオも導入予定です。

## ✨ ゲームの特徴

- **弱点を探す戦闘**：特殊ゴーグルを使い、敵ごとに異なる弱点を確認します。
- **アイテムの取得と鑑賞**：取得したアイテムを3Dで確認でき、回転・ズームして観察できます。
- **装備と物資の管理**：弾薬、回復、ライトやゴーグルを使い分けます。
- **導入演出**：ニュースや隊長の説明、ヘリコプターの演出で状況を伝えます。
